// ONE OBJECTIVE, EIGHT WAYS TO EXECUTE IT

The command center
under the chat box.

Missions

Durable objectives with success criteria, budgets, checkpoints and evidence. They pause, survive interruption and resume.

“Get the test suite green” → inspects, changes, tests, verifies.

Workflows

Describe a repeatable process and save it as a readable flowchart — executed by the same durable run engine as Missions.

“Run the weekly release-readiness workflow against this repo.”

Static Agents

Specialists with a model, a standing prompt and memory that carries across work. Switch from raw model to your release engineer in one click.

Describe your standards once — select the Agent forever.

Agent Apps

Ask the model to build the missing tool. Apps call APIs, hold encrypted secrets, run sandboxed shell — and stay available across conversations.

“Build a stock watcher with alerts” → approve once, reuse anywhere.

Design Systems

Generate a real token stylesheet from a brief or reference image. Preview the component gallery, restyle, save, reuse everywhere.

Your brand as tokens — decks and artifacts stay coherent.

Presentations

Research a subject, approve the slide-by-slide outline, generate a styled deck. Present fullscreen or export to PPTX.

Subject → outline → approval → deck. No blank-slide dread.

Visualizations

Simulations, state machines and interactive explainers with real controls — preserved as artifacts, not flattened into paragraphs.

“Show me how this algorithm behaves” → playable HTML.

Desktop + Mobile

The Electron app pairs with an Expo companion. A durable run started at your desk stays inspectable — and approvable — from your phone.

Desktop brain, pocket companion.

MCP + Skills

Register MCP servers and create reusable Skills — with slash commands — straight from the conversation. No installers, no silos.

“Turn this checklist into /release-audit” → done.

Permissioned Power

High capability, gated at the boundary. Every grant is visible, revocable, and enforced in the host process — not a hidden button.

Power when you enable it. A clear warning when it matters.

Computer Use

APIs first, the screen when needed. A distinct handover before any mouse or keyboard input — ordered, bounded, interruptible.

Look, act, look again — control released when the run ends.

Bring Your Models

Connect multiple providers, pick a model per conversation, dial thinking effort from none to max. The harness is open — yours, not a walled garden.

Your workspace, accounts, models and rules.
